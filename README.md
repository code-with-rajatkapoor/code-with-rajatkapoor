## 🚀 About me

I'm a full-stack developer and BCA student from **Kanpur, India**, building end-to-end web apps — UI, API, database, deploy. I like projects that solve a real problem for real people, and I ship them instead of leaving them half-finished in a folder.

- 🛡️ **Currently building** — [ScamGuard](https://scamguard-omega.vercel.app), an AI-assisted scam & phishing detector
- 📺 **Just shipped** — [CampusDash TV](https://campus-dash-tv.onrender.com/), a Fire OS dashboard built for hackathon demo days
- 🎓 **Studying** — BCA at VSICS, Kanpur (CSJMU), 2026–2029
- 🌱 **Learning** — system design, TypeScript patterns, and how to make AI actually useful
- 🤝 **Open to** — internships, freelance work, and open-source collaboration
- ⚡ **Fun fact** — my first reaction to any repetitive task is "I should automate this"
